# Contributing

PRs that keep skills aligned with [docs.cartesia.ai](https://docs.cartesia.ai) and OpenAPI are welcome.

Prefer **links** over copying values that drift (version date lists, exact field names). **cartesia-api** covers REST/WebSocket + SDKs. For Managed Agents (hosted voice agents, telephony), link the [Managed Agents docs](https://docs.cartesia.ai/agents/introduction)—do not add a second skill that duplicates that product surface.
