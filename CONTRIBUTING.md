# Contributing

PRs that keep skills aligned with [docs.cartesia.ai](https://docs.cartesia.ai) and OpenAPI are welcome.

Prefer **links** over copying values that drift (version date lists, exact field names). **cartesia-api** covers REST/WebSocket + SDKs. **cartesia-agents** covers Managed Agents through the Cartesia MCP; link the [Managed Agents docs](https://docs.cartesia.ai/agents/introduction) instead of copying them, and leave tool arguments to the MCP tool descriptions.
